# Project Writing

Writing for Project Zomboid Build 42: notebooks, diaries and sheets as real pages, freehand drawing, notes and symbols on paper and on the world map, shared in multiplayer.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3796402502
- Mod ID: `ProjectWriting`
- Author: Gimmi

## Layout

- `workshop/` is the mod exactly as it is uploaded: `workshop.txt`, the preview and `Contents/mods/ProjectWriting/`, with one folder per game build it supports.
- `art/` holds the cover and the images for the Steam page.
